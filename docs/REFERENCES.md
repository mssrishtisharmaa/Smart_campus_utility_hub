The home-page landscape at `public/images/monsoon-bharat.webp` is AI-generated concept artwork created for this project, depicting monsoon clouds above Indian farmland and a winding river. It is not a satellite image, meteorological observation or claim about a real event. Direction: cinematic aerial landscape, Western Ghats-inspired terrain, deep navy monsoon clouds, warm sunlight, lush fields, clean composition and no text. The interface uses original layout/code with Lucide icons; no third-party website screenshot is presented as our product.

Dataset-specific source links, coverage, units, licensing notes and integration status live in `lib/datasets.ts` and the public catalogue. Check provider terms again before commercial deployment. Public adapter verification is timestamped in `docs/source-verification.json`.
